# Assets

Place your media files here before deploying.

## Team photos
`/assets/team/<name>.jpg` — portrait photo for each barber
- mykhailo.jpg
- diana.jpg
- anton.jpg
- serhii.jpg
- yegor.jpg

Recommended: 600×800px, portrait orientation, JPG or WebP.

## Case photos
`/assets/cases/case<N>.jpg` — one photo per client case (1–8 provided by default)
- case1.jpg … case8.jpg

Recommended: 600×800px, portrait orientation.

## Location video
`/assets/location-video.mp4` — short video showing how to find the barbershop.
